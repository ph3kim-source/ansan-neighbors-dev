# 2안 기능 명세

> 안산 국적별 생활소비 지도 · 탭 5개
> 주 데이터(DS-056 외) 수급 전이므로 각 지표에 **[실데이터] / [보유데이터]** 표기를 둡니다.
> 화면 문구·정렬 규칙은 데이터가 들어와도 바뀌지 않습니다.

---

## 입력 (사이드바)

| 입력 | 값 | 비고 |
|---|---|---|
| **국적** | DS-026의 `cntry_nm` 21개국 중 관측된 것만 | 표본 최소 기준 미달 국적은 목록에 뜨지 않음 |
| **언어** | 국적→언어 매핑표로 국적 선택을 대체 | 86종에 없음 → 별도 수집(요청서 B-2) |
| **체류 유형** | 장기(1) / 단기(2) / 전체 | `in_forn_div_nm` |
| **목적** | 장보기 · 식사 · 송금·금융 · 통신 · 미용 · 의료 · 의류 | 업종 그룹 (요청서 B-3 필요) |
| **요일·시간대** | 평일/주말 × 0~23시 | DS-017 정시 기준 |

**국적 목록을 데이터가 정합니다.** 21개국 전부를 띄우지 않습니다.
안산에서 관측되지 않거나 표본 최소 기준(§표본 규칙)에 못 미치는 국적은 제외합니다.

## 탭 1 · 🌍 국적별 생활소비 지도 (원안 1 계승)

**입력** — 국적 + 목적 + 시간대

**지도 2레이어** (해상도가 다름을 범례에 명시)

| 레이어 | 단위 | 출처 |
|---|---|---|
| 동 색칠 = 친화도 | 행정동 25개 | DS-026 × DS-056 × DS-048 |
| 점 = 업종 점포 | 블록(100m급) / 좌표 | DS-048 / 보유 상가 34,489 |

**출력 지표 4종**

| 지표 | 의미 |
|---|---|
| 친화도 | `min(분위 방문집중도, 분위 LQ, 분위 점포실재)` — 0~1 |
| LQ | 그 국적이 그 동·업종에 유별나게 쓰는 정도. `>1` 이면 특화 |
| 적정 시간대 | `min(분위 DS-017 국적체류, 분위 DS-047 업종결제)` 최대 구간 |
| 표본 신뢰 | 관측 건수 구간 (◎ 100건+ / ○ 30~99 / △ 5~29 / 마스킹 <5) |

**안내 문구** — `"우즈베키스탄 국적 결제가 안산 평균보다 N배 몰리는 동·업종입니다"`
특화 업종이 없으면 그렇다고 말합니다. 없는 특화를 지어내지 않습니다.

## 탭 2 · 🔎 외지인이 찾아오는 가게 구조 (원안 2 계승)

**이 탭의 첫 줄에 함정 경고를 고정 배치합니다.**

> DS-056의 `gb` 는 외국인을 **전부 외지인(03)** 으로 분류합니다.
> 따라서 이 탭의 모든 수치는 **`nt` = 내국인으로 한정**해 계산했습니다.

**출력**

| 지표 | 산출 | 읽는 법 |
|---|---|---|
| 내지인 비중 | `amt(gb=01)/amt(all)` | 높으면 동네 주민 전용 |
| 인접지인 비중 | `amt(gb=02)/amt(all)` | 경기도 내 다른 동에서 옴 |
| 외지인 비중 | `amt(gb=03)/amt(all)` | 경기도 밖에서 옴 |
| 객단가 순위 | `amt/cnt` 의 **동·업종 내 분위** | 절대금액 비공개 |
| 유입 출발지 | DS-050 `inflow_cd` 상위 | 경기 내=행정동 / 밖=시군구 |

**"숨은 맛집" 정의** — 외지인+인접지인 비중이 상위이면서 점포 수는 하위인 동·업종.
= 가게가 적은데 멀리서 찾아온다.

**교차 탭** — 탭 1의 국적 소비와 이 탭의 내국인 소비를 같은 동에서 겹쳐 봅니다.
둘이 분리되어 있으면(§설명 6-④) **분리 그래프를 그대로 표시**합니다.

## 탭 3 · 🗺️ 반나절 동선

**동선 = 동 2~3스톱.** 경로 탐색이 아닙니다.

**생성 규칙**

```
1. 후보 동   = 선택 국적·목적의 친화도 상위 동
2. 연결 가능 = DS-004·005 행정동간 OD 에서 실제 관측된 동→동 전이만
               (관측되지 않은 이동은 제안하지 않음)
3. 시간 배치 = 각 스톱의 적정 시간대가 겹치지 않게 순서 결정
4. 이동수단  = DS-005 `TRANS_GB` 비중 상위 (0=차량 1=노선버스 2=지하철 3=도보)
```

**출력** — 스톱별 `동 · 시간대 · 업종 · 친화도` + 구간별 실제 이동수단 비중

**하지 않는 것** — 정류장·환승·소요시간. 그건 3안(보행)·4안(통근) 영역입니다.

## 표본 규칙 (모든 탭 공통)

```
cnt < 5   → 마스킹 (표시하지 않음)
cnt 5~29  → △ 참고값
값 파싱   → float 명시 (8.84e-06 같은 값이 나옴, 반올림 금지 · Q-21)
금액 표시 → 절대값 금지. 분위·배수·순위만
```

인벤토리는 DS-001 등의 민감도 판단 근거에 "소표본 구간은 마스킹 권장"을
명시하고 있습니다. 국적 × 업종 × 동은 3중 세분화라 소표본이 구조적으로 많이
생기므로 마스킹 규칙을 계산 단계에 넣습니다.

## 데이터 계약 (실데이터 교체 지점)

**아래 4개 스키마만 채우면 화면 코드는 한 줄도 고치지 않습니다.**

```
nat_dong.csv    ym, adm_cd, cntry, stay_type, pop            ← DS-026
nat_dong_hour   ym, adm_cd, cntry, stay_type, hour, pop      ← DS-017
nat_biz.csv     ym, adm_cd, biz_cd, biz_nm3, gb, nt, amt, cnt ← DS-056
store.csv       ym, blk_cd, lon, lat, adm_cd, biz_cd, n_alive ← DS-048 (+blk 좌표표)
```

| 스키마 | 현재(보유) | 실데이터 |
|---|---|---|
| `nat_dong` | 없음 → 행안부 외국인주민 현황으로 대체 예정 | **DS-026** |
| `nat_dong_hour` | **대체 불가** → 시간대 기능 비활성 | **DS-017** |
| `nat_biz` | **대체 불가** → 탭 1·2 비활성 | **DS-056** |
| `store` | 보유 상가 34,489 (좌표 있음, 업종체계 다름) | **DS-048** + blk 좌표 대응표 |

교체 지점은 로더 4개뿐입니다. 친화도·LQ·동선 로직은 스키마만 보고 돕니다.
