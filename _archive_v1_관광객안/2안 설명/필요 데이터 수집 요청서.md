## A-보조. 인벤토리에 정의가 없어 별도로 받아야 하는 코드표 3건

> 이 3건은 데이터가 아니라 **문서**입니다. 용량은 0이지만 없으면 데이터를 해석할 수 없습니다.
> 인벤토리 `03_컬럼사전` 에 "참조하라"고만 적혀 있고 실제 표가 첨부돼 있지 않습니다.

### ★ 보조1. `nt` (국적명칭) 코드표 — **최우선**

- **근거**: 인벤토리 03 시트 DS-056 `nt` 항목의 코드값 설명이
  **"외국인 국적코드 sheet 참조"** 인데, 인벤토리에 그 시트가 없습니다.
- **실제 값 예시**: `04_규격_실측_비교` 의 DS-056 샘플 1행이 `nt = '000'` 입니다.
  `'000'` 이 내국인인지 미분류인지 확인해야 합니다.
- **없으면**: `nt` 를 해석할 수 없어 국적 구분이 불가능합니다.
  §A-1 DS-056을 받아도 **쓸 수 없습니다.**
- ★ **조인 키 불일치가 핵심 문제입니다.**
  통신 쪽(DS-017·026·028)의 국적은 `CNTRY_NM` = **한글 국적명 텍스트**입니다
  (실제 샘플 확인값: `중국`). 카드 쪽(DS-056)의 국적은 `nt` = **3자리 코드**입니다
  (실제 샘플 확인값: `000`).
  친화도는 두 데이터를 **같은 국적으로 묶어야** 계산되는데 키 체계가 다릅니다.
  → 요청할 것은 코드표 그 자체이며, 받은 뒤 **`nt` 코드 ↔ `CNTRY_NM` 국적명
  대응표를 별도로 만들어야** 합니다. 코드표가 없으면 국적 데이터가 양쪽에 다
  존재해도 **연결이 불가능**합니다.
- **요청 대상**: 카드사 규격서 부속 코드표 / 경기도 공동구매 사업 담당 부서

### ★ 보조2. 카드 업종분류 코드표 (`card_tpbuz_cd` 대·중·소분류 전체 목록)

- **근거**: 07 코드값사전에 "카드사 자체 업종분류 대/중/소분류명"이라고만 적혀 있고
  코드 목록이 없습니다. 샘플로 확인된 것은 `D01`=소매/유통, `D01003`=컴퓨터/주변기기,
  `F01`=생활서비스(광고/인쇄/인화) 정도입니다.
- **없으면**: 목적군(장보기·식사·송금·통신·미용·의료·의류) 정의가 불가능합니다.
  파라미터 #9가 **C등급으로 고정**됩니다.
- **특히 확인할 것**: **송금·환전 업종이 카드 업종체계에 존재하는가.**
  외국인 생활소비에서 가장 큰 항목인데 카드 결제가 아니라 없을 개연성이 있습니다.
- **요청 대상**: 동일

### 보조3. `blk_cd` (블록코드) → 좌표·경계 대응표

- **근거**: 07 코드값사전 — "카드사 자체 공간 그리드. 좌표계 WGS84(SRID:4326)".
  코드는 `159533` 같은 숫자인데 그것이 어디인지 알 수 있는 표가 없습니다.
- **없으면**: DS-048·050·054의 블록 데이터를 **지도에 올릴 수 없습니다.**
  행정동 집계로만 써야 하고, 그러면 블록 데이터를 받는 의미가 절반으로 줄어듭니다.
- **참고**: 3안도 같은 문제를 안고 있습니다. 공통 자산이므로 한 번 받으면 재사용됩니다.
- **요청 대상**: 동일

   - 행정동 × 업종 × 국적(nt) 단위 소비 집중도(입지계수) 산출

   - 관측 건수 5건 미만 셀은 마스킹 (소표본 마스킹 권장 지침 준수)

### C-2. 코드표 요청

```
[요청] 데이터 해석에 필요한 코드표 3건을 요청합니다.
인벤토리(안산시_민간데이터_데이터셋_인벤토리_v1.0.xlsx)의 03_컬럼사전에
"참조" 표기만 있고 실제 표가 첨부되어 있지 않은 항목입니다.

1. GGC_SALES_YM_AMD 의 nt(국적명칭) 코드표
   - 컬럼 설명에 "외국인 국적코드 sheet 참조"로 기재되어 있으나 해당 시트 없음
   - 확인된 실값 예시: '000'
   - 이 표가 없으면 해당 데이터셋의 국적 구분을 해석할 수 없습니다.
   - 아울러 nt 의 국적 판정 기준을 함께 회신 요청합니다.
     (규격서·인벤토리에 판정 기준이 기재되어 있지 않습니다)
     · '000' 이 내국인인지 미분류인지
     · 외국인이 내국인 명의 카드를 사용한 경우의 집계 처리
     · 귀화자·복수국적자의 분류 기준
     · 법인카드의 nt 값
     · 통신 데이터 CNTRY_NM(한글 국적명, 21개국)과의 대응 관계

2. card_tpbuz_cd 업종분류 코드표 (대·중·소분류 전체)
   - 07_코드값사전에 "카드사 자체 업종분류"로만 기재
   - 확인된 실값 예시: D01(소매/유통), D01003(컴퓨터/주변기기), F01(생활서비스)
   - 특히 송금·환전 관련 업종의 존재 여부 확인 필요

3. blk_cd(블록코드) → 좌표 또는 경계 대응표
   - 07_코드값사전에 "카드사 자체 공간 그리드, WGS84(SRID:4326)"로만 기재
   - 확인된 실값 예시: 159533
   - 이 표가 없으면 블록 단위 데이터를 지도에 표출할 수 없습니다.
```
