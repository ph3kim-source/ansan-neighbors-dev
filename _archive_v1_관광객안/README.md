## 이것은 서비스가 아닙니다

주 데이터(DS-056 · DS-026 · DS-048)를 한 건도 수급하지 못한 상태의
**현황판(baseline)** 입니다. 매뉴얼의 5대 기준으로 스스로 판정한 결과
3개가 미달이고, 사유를 `docs/5대기준_판정.md` 와 앱 「근거 대장」 탭에 그대로 둡니다.

| # | 기준 | 판정 | 사유 / 해소 조건 |
|---|---|---|---|
| 1 | 데이터 실종 테스트 | **미달** | 86종 민간데이터를 한 건도 쓰지 못함 → DS-056 승인 |
| 2 | 숫자 계산 가능성 | 충족 | 모든 수치가 `src/validate.py` 에서 재현됨 |
| 3 | 시민 중심성 | **미달** | 정착 장애요인 1·2위(73.1%)를 상권 데이터로 풀 수 없음 |
| 4 | 멀티데이터 결합 | **미달** | 6대 카테고리 중 '외국인 도메인' 하나만 사용 |
| 5 | 안산시 특수성 | 충족 | 원곡동 83.8% · 구별 체류자격 구조 상이 |

**③은 데이터가 와도 자동으로 해소되지 않습니다.** 문화적 차이(39.5%)와
사회적 편견(33.6%)은 상권 데이터로 풀리는 문제가 아니기 때문입니다.

## 재설정 이력 — 초판에서 제거한 것

초판 프로토타입은 **C등급 구성물을 A등급인 것처럼 화면에 올렸습니다.**
전부 제거했습니다. 근거는 `src/params.py` 주석과 `docs/근거대장.md` 에 있습니다.

| 제거 | 왜 |
|---|---|
| **생활 목적 10종** | 「2안 근거.md」 #9가 이미 '업종 그룹 = C등급'으로 판정해 둔 것을 무시하고 7→10개로 늘려 확정 축처럼 표시. 그중 4개(일자리·주거·여행·생활)는 원 기획에도 없고 점포 LQ가 튀는 것을 보고 사후에 붙인 이름 |
| **국적권 점포 372곳** | 상호명 국적 추정. 포착률 55~63%(40% 이상 누락), 오탐률 미검증. 초판 사전은 '만두' 568곳·'중국집' 427곳을 국적 신호로 오인해 포착률 250~368%의 과포착 |
| **'친화도' · '외국인 생활 인프라'** | 인력공급업 점포가 외국인 대상이라는 근거가 어느 데이터에도 없음. 합성 지표에 해석적 이름을 붙이지 않음 |
| **반나절 동선** | OD·도보 네트워크가 없어 중심점 거리로 이어붙였는데, 거리는 근거가 아니고 순위표를 왜곡(2위 0.79를 빼고 4위 0.73을 넣음) |
| **"추정치 없음 · 전부 실측" 문구** | 사실과 다름. 국적권 점포가 추정이었음 |

대신 **업종을 묶지 않고** 업종소분류 245종을 시민이 직접 고르게 했습니다(X등급).

## 화면 (5탭)

| 탭 | 내용 | 등급 |
|---|---|---|
| 🗺️ 동별 인구 | 동 25개 × 외국인주민·등록외국인·동포 + 10개월 추이 | A (공표 원값) |
| 🌏 국적 · 체류자격 | 구 2개 × 국적 120 × 체류자격 8 | A (공표 원값) |
| 🏪 업종 분포 | 업종소분류 선택 → 동별 LQ · 외국인비중 산점도 | A (실측 + 산술) |
| 🙋 수요 | 정착 장애요인 · 보건소 이용 · 도서관 이용 | 원자료 전사 |
| 📋 근거 대장 | 파라미터 등급 · 5대 기준 판정 · 검증 기록 | — |

**동시분위 = `min`(외국인비중 분위, LQ 분위)** — 가중합이 아닙니다.
3안은 가중치 변경으로 경로의 98%가, 4안은 집결지의 50~85%가 뒤바뀌어
가중합을 폐기했습니다. `min` 은 가중치도 정규화 상수도 없습니다.

두 축이 같이 높다고 해서 **그 점포를 외국인이 이용한다는 뜻은 아닙니다.**
이용자 정보는 어느 보유 데이터에도 없습니다.

### ① 이 프로젝트에서 가장 위험했던 함정

구 시트의 **`총계(ⓐ+ⓑ)` 헤더는 실제와 다릅니다.** 값은 등록외국인(ⓐ)만 담고 있습니다.

```
한국계러시아인  실제  7,245 → 등록만    383  (95% 누락)
우즈베키스탄    실제  9,809 → 등록만  2,871  (71% 누락)
한국계중국인    실제 50,530 → 등록만 16,991  (66% 누락)
카자흐스탄     실제  3,542 → 등록만  1,315  (63% 누락)
```

`total_all = 등록외국인 + 외국국적동포` 로 재계산했습니다.
