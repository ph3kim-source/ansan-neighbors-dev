## 3. 남은 일 (우선순위 순)

1. **브라우저 실사용 점검** — 테스트는 예외 여부만 확인함. 지도 툴팁, 팝오버(댓글·신고), 다크모드 색, 모바일 폭은 눈으로 확인하지 않았음.
2. **관리자 '공지·정책·행사 작성' 화면** — 저장 함수 `cm.add_notice()`는 있으나 입력 폼이 없음 (결정 R5-20).
3. **커뮤니티 보완** — 장터 상태 변경(판매중→예약→완료), 내 글 수정·삭제, 목록 페이지 나누기, 언어방 리더 권한(1차 신고 처리).
4. **지도 클릭 선택** — 지금은 '동네 살펴보기' 셀렉트박스로 동을 고름. pydeck `on_select`로 지도 클릭 연동.
5. **번역** — 시드 글만 번역이 내장됨. 새 글은 "(번역 API 연결 후 제공)" 표시. 번역 API 연동 시 `community.add_post`에서 `body_ko` 채우기.
6. **내국인 이웃 페르소나** — 교류방 전용 규칙은 코드·테스트에 있으나 시연 페르소나 없음 (`config.PERSONAS`에 추가하면 됨).
7. **행정 접점 QR 랜딩 · 단톡방 공유 링크** (결정 R3-12).
8. **실데이터 교체** — `data/synthetic/` 파일을 실제 납품 파일로 바꾸고 `docs/기획_결정사항.md` §6 가정(21개국 목록, 국적코드, 업종코드, DS-042/061 헤더)을 실제 값으로 갱신. 배지 문구 수정.
9. **경량성 검토** — 기능이 많음. 장터·사업장 후기 운영 인력을 산정한 뒤 MVP 범위를 줄일지 결정 (AGENTS.md 경량성 원칙).
10. **용량** — DS-017 가상 원본이 약 100MB. 공유·배포 시 `data/synthetic/T38_*`는 빼고 `gen_synthetic.py`로 다시 생성하도록 안내.
