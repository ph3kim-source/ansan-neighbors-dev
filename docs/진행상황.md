## 1. 실행

가장 쉬운 방법:
- **시연판 링크(누구나, 설치 없음)**: https://ph3kim-source.github.io/ansan-foreign-community-demo/ — 첫 화면(소개 · QR · PC 는 폰 틀 미리보기) · `app/` 시민 앱 · `summary/` 제안 요약. 늘 가상 판이고, 글은 보는 사람 브라우저 안에만 남는다(콘솔과 이어지지 않음).
- **시민 앱**: `2안\앱_실행.bat` → http://127.0.0.1:8600 (휴대폰 크기로 보려면 F12 → 기기 툴바). `data\real` 이 있으면 실데이터(고향 사람 지도 = 실제 통신 자료), 없으면 가상 판으로 연다(2026-11-20 사용 승인). 같은 와이파이의 휴대폰으로 보려면 `앱_휴대폰으로_보기.bat`.
- **운영 콘솔(공무원)**: `2안\실행.bat` → Streamlit (Python 3.13 경로 고정, 가상 데이터 없으면 자동 생성, `data\real` 이 있으면 실데이터 · 127.0.0.1). 시민 앱과 같은 커뮤니티 DB 를 쓴다.

```powershell
cd "C:\Users\master\Desktop\my project\2안"
python src\gen_synthetic.py      # 가상 데이터 6종 + 집계 캐시 3개 (약 1분, 최초 1회)
python src\community.py          # 커뮤니티 DB 초기화·시드 (선택: 앱이 비어 있으면 자동 시드)
python pipeline\stage_licenses.py  # 안산 식품 인허가 8종(공공, 키 없음) → data/public/raw/localdata (git 제외 · 가게 갱신 전에 다시 받기)
python pipeline\stage_shops.py  # 시민 앱 가게 목록 — 공공 상가정보에서 고르고 인허가 대장으로 영업 확인 → shops_ansan.csv(지도) · shops_unverified.csv(확인 대기)
python src\server.py             # 시민 앱 (http://127.0.0.1:8600)
streamlit run src\app.py         # 운영 콘솔
python -m pytest tests -q        # 테스트 67개 (화면·커뮤니티·API 시험은 임시 DB — data/community.db 를 건드리지 않음)
python pipeline\build_html.py    # HTML 판 — html\안산이웃_플랫폼.html(시민 앱 그대로) · html\안산이웃_제안요약.html (늘 가상)
```

실데이터 판(내부 검토용): `python pipeline\stage_real.py` + `python pipeline\stage_grid.py`(50m 격자, 수 분) + `python pipeline\stage_roads.py`(격자 칸 거리 이름, 1분 안팎) — 구글 드라이브가 켜져 있어야 함 → 그 뒤로는 `실행.bat` · `앱_실행.bat` 이 저절로 실데이터 판으로 연다(실데이터 전용 실행 파일 두 개는 2026-11-23 `../_보관/2안_실데이터_실행파일_20261123/` 로 옮김).
`data/real` 은 git · 공유판 · 드라이브 앱에서 모두 막혀 있다. 대화 · 로그에 원자료 행을 찍지 않는다.

예전 `data/community.db` 는 지우지 않아도 된다 — 앱이 켜질 때 새 칸(공지 `target_dongs`·`scope`)과 새 시연 사용자(내국인 이웃)를 채운다.

## 5. 알려진 한계

- 가상 판의 수치는 모두 **가상**이다. '우즈벡 1위 = 선부2동' 같은 결과는 시나리오 가정(`gen_synthetic.AFFINITY`)에서 나온 것이다. 실데이터 판과 비교한 결과는 비공개 문서에 있다.
- 실데이터 판의 '사는 곳'은 밤에 머무는 곳 추정이다. 산단 기숙사와 야간 근무자가 섞이고, 통신 21개국 밖 국적(우크라이나 · 키르기스스탄 등)은 '기타'로 묶인다.
- 실데이터 판의 연휴 인파에는 다른 시에 사는 같은 국적 주민도 섞인다. 국적별 결집 배수는 관리자 화면에만 둔다.
- 회원 수·활동·KPI 가입률의 분자(가입자)는 시드로 만든 가상값이다.
- 행사 4건(설맞이·나브루즈·세계인의 날·체육대회)과 공공시설 핀은 예시이며, 위치는 동 중심점 근처의 가상 좌표다.
- 공지 작성의 '번역 언어 추천'과 '받는 회원 수'는 시드로 만든 가상 회원 DB에서 센다. 실제 서비스에서는 가입 회원이 쌓여야 의미가 있다(대상 국적 회원이 없으면 번역 추천이 빈다 — 국적 기본 언어 가정 `config.NATIONS` 로 대신 채우는 기능은 아직 없음).
