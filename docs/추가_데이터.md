# 2안 — 필요한 추가 데이터

> 2026-11-23 · 사용자: "필요한 추가 데이터 따로 정리하고 진행해봐".
> 앱이 더 필요로 하는 자료를 두 갈래로 나눴다. 공개 자료로 바로 구할 수 있는 것은 이번에 넣었다(§1), 나머지는 아직 필요한 것이다(§2).
> 민간 실데이터(인벤토리) 이야기는 이 공개 문서에 숫자를 적지 않는다. 그 숫자는 프로젝트 루트의 비공개 문서에 있다.

공공 기관 위치는 이렇게 정했다. 주소만 있는 목록이 많아서 같은 건물의 공개 좌표를 썼고, 출처 두 곳이 서로 맞는지 확인했다(`data/public/facilities.csv` 의 `located_by` 칸).
- 단원보건소: 심평원 좌표와 같은 건물의 상가정보 좌표가 5m 차이다.
- 가족센터: 같은 건물 1층 영업소의 인허가 좌표와 OpenStreetMap 의 '안산 글로벌다문화센터'가 6m 차이다.
- 고용복지플러스센터: OpenStreetMap 의 옛 이름 '안산종합 고용지원센터'가 상가정보의 이웃 번지(원고잔로 15)와 31m 차이다.
- OpenStreetMap 에 있던 '안산단원보건소'는 1.6km 떨어져 있어 쓰지 않았다. 원곡동의 지원본부는 OpenStreetMap 에 없었다.
