## 0. 한 줄 정의

안산에 사는 외국인 주민(갓 온 사람 ~ 장기 거주자)이
① 같은 국적 사람들이 **사는 곳·모이는 곳·돈 쓰는 곳**을 데이터 지도로 확인하고,
② **언어방 익명 커뮤니티**(에브리타임식)에서 정보를 나누며,
③ 안산시가 올리는 **국적별 행사·정책**과 **공식 Q&A**를 받아보는 사이트.
안산시는 **공지·소통 창구**로 운영하고, 관리자 화면에서 생활권 동향·행사 효과·전입 정착을 **집계 수준**으로만 본다.

## 5. 리스크 · 태클 기록

1. **기준① 탈락 위험** — 커뮤니티 절반은 데이터와 무관. → 커뮤니티 화면 곳곳에 데이터 기능 노출(생활권 자동 설정, 모임 장소 추천, 새로 온 이웃).
2. **빈 게시판(cold start)** — 에타처럼 학교 단위 자연 유입이 없음. → 리더 위촉·시드글, 행정 접점 QR, 단톡방 연동.
3. **사업장 후기 법적 위험** — 명예훼손·업무방해. → 업종·동 단위 익명화, 사업장명 입력 차단, 노동 상담 연결.
4. **장터 사기** — 시 운영 책임 논란. → 물품만, 결제·보증 없음, 신고 3건 시 자동 숨김.
5. **국적 밀집 노출** — 혐오·단속에 악용될 수 있음. → 시민 화면은 동 단위 + 마스킹, 격자는 관리자 전용.
6. **'관리' 프레이밍** — 감시로 오해받을 수 있음. → 공지·소통 창구로 한정, 체류자격 미수집.
7. **DS-076 과소추정** — '우량외국인'(신용정보 보유자)만 집계됨. → 화면에 한계 명시.
8. **운영 인력** — 언어방 리더 위촉 예산·교육 필요.
9. **기존 서비스와 중복** — 하이코리아·다누리·외국인주민지원본부. → 안산 정책 + 공식 Q&A + 데이터 지도로 차별화.
10. **경량성 원칙(AGENTS.md)과의 긴장** — 기능이 많음. → 업그레이드 단계에서 MVP 범위를 잘라낼 필요.
